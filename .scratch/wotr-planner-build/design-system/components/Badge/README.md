# Badge

A small chip with a mark and a word.

**Variants:**
- `--open`, `--closed` and `--gear` are status.
- `--mythic` marks a Mythic option.
- `--link` is a Synergy link ("→ enables", "← needs").

Color comes from `currentColor`, so the border matches the text.

**Do:** always pair the mark with its word.

**Don't:**
- use a badge for the accent;
- invent new colors: status has exactly three.

# Refusal

The reasons an option is closed, one line each, worded true for this Build by R.

**Markup:** `ul.ww-refusal`, one `li` per unmet need, each prefixed with ✕ in `closed`. What the character has goes in `.ww-refusal__have`, in `ink-muted`. `.ww-refusal--gear` is the gear-dependent note, marked ◈ in `gear`.

**The consumer provides:** R's lines, unchanged. They cover:
- unmet prerequisites, read through P: "Needs Strength 13 (yours: 10).";
- later picks it would break;
- the level where it opens.

**Do:** keep each need on its own line, short and in the second person.

**Don't:** reword R's text, truncate it, or show it only on hover.

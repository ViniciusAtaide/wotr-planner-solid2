# Cascade edits: clear only, or move picks?

Type: grilling
Status: resolved
Parent: [map](../map.md)

## Question

Scenario: level 2 changes from Fighter to Wizard.
- Fighter's level-2 bonus-feat slot disappears, and Wizard's arcane school slot appears.
- Picks still legal in the new shape stay.
- Picks in slots that no longer exist are cleared and listed in the preview.
- A later Fighter feat that needed a class level the Build no longer reaches is cleared too.

Should a Cascade edit ever **move** a pick to an equivalent slot (the bonus feat into a general slot), or only clear? Also: does changing ability scores, race or a Mythic rank level cascade the same way?

Proposed: only clear, never move.

## Answer

User, 2026-11-19.

- **Always clear, never move.** A pick broken by an edit is removed and its slot left empty. The planner never guesses an equivalent slot for it. Undo restores everything the cascade cleared.
- **One rule for every edit:** a level's class, ability scores, race, archetype, alignment, removing Gear (for gear-dependent picks) and moving a Mythic rank's Rank level all work the same way. After the edit, the walk re-judges the whole Build, and every pick that now fails, or whose slot no longer exists, is what the edit breaks.
- **A plain edit** that breaks anything is refused, naming those picks.
- **A Cascade edit** lists them first, then applies the edit and clears them.

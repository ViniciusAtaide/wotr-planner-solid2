# Whose builds: main character only?

Type: grilling
Status: resolved
Parent: [map](../map.md)

## Question

Does v1 plan only the main character, or companions and mercenaries too? Companions join at fixed levels with picks already made, and some rules apply only to the main character: `EquipmentRestrictionMainPlayer`, `PrerequisiteMainCharacter`, and Trickster's ignore-feat-prerequisites flag, which applies to `BasicFeatSelection` for the main character only.

Proposed in the grilling session: main character only, so every Build is a main character and those rules always apply.

## Answer

User, 2026-11-19: main character only. Every Build is the main character, so `EquipmentRestrictionMainPlayer` and `PrerequisiteMainCharacter` always pass, and Trickster's waiver on `BasicFeatSelection` is available whenever the Build holds it. The Build has no "whose" field and no switch. Companions and mercenaries are out of scope for this map.
